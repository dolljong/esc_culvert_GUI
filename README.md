# ESC Culvert — 암거 설계 프로그램 (웹)

브라우저에서 동작하는 암거(box culvert) 설계 프로그램. 화면 구성과 설계 흐름은
사용자 설명서(`docs/A-Culvert-매뉴얼`)를 따른다: 상단 드롭다운 메뉴, 설계 순서대로
구성된 메뉴트리, 검은 바탕의 입력결과 확인창, 엑셀형 항목별 세부 입력창.
선형·구간·단면 입력부터 하중·2D 골조해석·단면검토, 배근, 도면/계산서/수량산출서 출력까지 한다.

빌드 도구나 서버 사이드 로직이 없는 **정적 웹앱**이다. HTML/CSS/바닐라 JS(ES 모듈)만
쓴다. 설치할 의존성도, 실행할 빌드도 없다.

> 이 저장소는 원래 PyQt5 데스크톱 프로그램이었다. 전환 직전 상태는 `pyqt-final`
> 태그에 있고, 아직 웹으로 옮기지 않은 메뉴의 계산 로직을 참조할 수 있도록
> `legacy_pyqt/`에 동결 사본을 두었다. **참조용이며 유지보수하지 않는다** —
> 기능 수정은 웹 구현에만 한다.

---

## 실행

ES 모듈은 `file://`에서 CORS 정책상 로드되지 않는다. **반드시 HTTP로 서빙**해야 한다.
`index.html`을 파일 탐색기에서 더블클릭하면 빈 화면만 나온다.

저장소 루트에서:

```bash
python serve.py          # 개발용 서버 (브라우저 캐시를 끔, 기본 포트 8000)
```

접속: `http://localhost:8000`

`python -m http.server` 나 `npx serve .` 로도 실행되지만, 이 둘은 캐시 금지 헤더를 보내지 않는다.
그래서 JS 를 고쳐도 브라우저가 예전 모듈을 계속 쓸 수 있다. 강력 새로고침(`Ctrl+Shift+R`)으로도
동적으로 불러오는 모듈은 갱신되지 않는 경우가 있으니 개발할 때는 `serve.py` 를 쓴다.
이미 예전 파일이 캐시에 남았다면 개발자 도구(F12) Network 탭의 **Disable cache** 를 켜고 새로고침한다.

## 사내 서버 배포

정적 파일만 올리면 된다. 웹서버(nginx / IIS / Caddy 등) 문서 루트를 이 저장소
루트로 지정한다. 애플리케이션 서버, 데이터베이스, 런타임 모두 필요 없다.

```
/index.html
/css/       esc-culvert.css
/js/        main.js, core/, ui/, cad/, calc/, draw/, screens/, utils/
/docs/      A-Culvert 사용자 설명서, 개발 가이드
```

### 서버 설정에서 반드시 확인할 것

| 항목 | 이유 |
|---|---|
| `charset utf-8` | 파일과 UI 전체가 한글이다. 빠지면 글자가 깨진다. |
| `.js` → `Content-Type: text/javascript` | ES 모듈은 MIME 타입이 틀리면 **로드 자체가 거부**된다. |
| `.js`/`.css`에 `Cache-Control: no-cache` | 사용자 브라우저에 구버전이 박히는 사고를 막는다. |

nginx 예시:

```nginx
server {
    listen 80;
    server_name culvert.example.local;
    root /srv/esc_culvert;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(js|css)$ {
        add_header Cache-Control "no-cache";
    }
}
```

배포 후 헤더에 표시되는 버전(`js/core/model.js`의 `APP_VERSION`)을 올려두면,
설계자들이 서로 다른 버전을 보고 있는 상황을 화면 우하단에서 바로 확인할 수 있다.

## 데이터가 저장되는 위치 — 중요

**서버에는 아무것도 저장되지 않는다.** 백엔드가 없기 때문이다.

- 작업 내용은 접속한 **브라우저의 localStorage에 자동 저장**된다(변경 후 1초).
  하단 상태 표시줄에서 마지막 자동저장 시각을 볼 수 있다.
- 따라서 데이터는 **그 PC, 그 브라우저에만** 남는다. 다른 설계자에게 보이지 않고,
  같은 사람이라도 다른 PC에서 접속하면 보이지 않는다.
- 브라우저 데이터 삭제, 시크릿 모드, 접속 주소(호스트·포트) 변경 시 사라진다.

### 그래서 프로젝트 공유·보관은 파일로 한다

- **저장**(`Ctrl+S`) — 현재 프로젝트를 `.ecu` 파일(JSON)로 저장한다.
- **열기**(`Ctrl+O`) — `.ecu` 파일을 연다. 이전에 `.acu` 로 저장한 파일과 이전 버전의 JSON 도 열린다.

중요한 작업은 `.ecu` 파일로 저장해 공용 드라이브에 보관하는 것을 권장한다.

> 여러 설계자가 서버에 프로젝트를 공유 저장해야 한다면 백엔드가 필요하다.
> 그때를 대비해 저장 계층은 `js/utils/storage.js` 한 파일에 격리해 두었다
> (`setBackend()`로 교체). 폼이나 화면 코드는 수정할 필요가 없다.

## 기능

메뉴트리를 위에서부터 차례로 입력하면 설계가 끝난다. [이전]/[다음]은 현재 암거 형식에서
쓰지 않는 단계(회색)를 건너뛴다.

| 메뉴 | 화면 |
|---|---|
| 기본 설정 | 프로젝트 정보, 암거 표준도, 선형 정보(평면 IP+클로소이드 / 종단 / 지반고 / 편경사), 암거 기본 구성 (Box형·U형·복층형·지하차도) |
| 일반 입력 | 구간 설정(신축이음·다웰바), 지반 정보, 종단 제원(지하차도), 단면 제원, 횡단 제원(차도부·측구), 기둥 배치, 기초 형식, 기초부 설정(직접기초 지지력 / 말뚝), 현장타설말뚝 제원 |
| 상세입력 | 난간벽·차수벽, 날개벽 위치/제원(일체식·옹벽식), 접속 슬래브, 시공 이음, 토공 상세 |
| 구조 계산 | 설계 조건, 검토 위치 설정(부력·지지력 검토), 하중 조합, 하중 정의, 하중 조합(옹벽), 2D Frame 해석, 3D Plate 해석(MIDAS mct 생성·anl 읽기), 단면 검토 위치 설정, 종방향 거더 해석(기둥 지점 연속보 · 휨/전단/균열 검토) |
| 배근 입력 | 배근 설정, 주철근(1/3/2,4 Cycle), 차도부, 헌치·단절점부·브래킷, 수평 철근, 철근 배치, 전단 철근, 보·기둥 철근, 날개벽·접속슬래브·기타 철근, 철근 제원(재료표) |
| 출력 | 도면 출력(일반도·구조도·철근재료표, DXF), 구조계산서(미리보기·Excel), 옹벽 구조계산서, 수량산출서(일반·공통·토공, Excel) |

### 해석
원본은 SAP2000/MIDAS 와 연계하지만, 웹판은 **브라우저 내장 2D 골조 해석기**(`js/calc/frameSolver.js`,
직접강성법)로 바로 푼다. 하부 지반은 스프링(Spring) 또는 압축 전용 스프링(NLLink), 지진시 응답변위법은
벽체 스프링을 둔다. 검증용으로 SAP2000 `.s2k`, MIDAS `.mct` 입력파일을 내려받을 수 있다.

### 입력창 조작 (매뉴얼 1.2)

| 키 | 동작 |
|---|---|
| 셀 선택 후 입력 / Enter / Tab / 방향키 | 엑셀과 같은 셀 편집·이동 (F2, 더블클릭: 수정) |
| `=` 로 시작 | 수식 입력 (예: `=4500*2+500`, `=SQRT(2)*300`) |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 드래그로 선택한 행열을 엑셀과 주고받기 |
| `Ctrl+Z` / `Ctrl+Y` | 취소 / 복구 (빠른실행의 빨간 버튼: 전부취소) |
| `Alt+P` / `Alt+N` / `Alt+A` / `Alt+D` | 이전 / 다음 / 적용 / 기본값 |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 새 파일 / 열기 / 저장 (`.ecu`) |
| 확인창 휠 / 드래그 / 더블클릭 | 확대·축소 / 화면이동 / 전체보기 |
| 확인창의 노란 변수명 클릭 | 해당 입력셀로 이동 |

## 코드 구조

```
index.html, css/esc-culvert.css   프로그램 틀 (Office 2007 파란 테마)
js/main.js                     진입점: 파일, 자동저장, 단축키
js/core/                       store(경로 기반 상태·실행취소), model(데이터 구조·기본값), menu(메뉴 순서)
js/ui/                         shell(메뉴·트리·다이얼로그), grid(엑셀형 그리드), cells, dom, formula
js/cad/                        Drawing(엔티티), CadView(확인창), dxfWriter(R12 DXF)
js/calc/                       선형, 단면형상, 지반, 하중, 조합, 골조해석, 단면검토, 배근, 철근제원, 계산서, 수량, 도면 시트
js/draw/                       단면도·평면도·종단도·부재력도·철근도·도각·표
js/screens/<id>.js             메뉴 화면 하나 = 파일 하나
legacy_pyqt/                   전환 이전 PyQt5 원본 (참조용 동결)
```

화면 추가·수정 방법과 데이터 소유 규칙은 `docs/DEV_SCREENS.md` 에 있다.

이전 버전(단일 단면판)의 JSON 파일은 파일 메뉴의 [가져오기]로 열 수 있다.
